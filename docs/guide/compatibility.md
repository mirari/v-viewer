# 兼容性

| 环境      | 支持                                 |
| --------- | ------------------------------------ |
| Vue       | 3.0+                                 |
| Viewer.js | 1.11.7+ (1.x)                        |
| SSR       | 支持导入；DOM 操作仅在浏览器中执行。 |

Vue 3 需要现代浏览器。`<script setup>` 示例要求 Vue 3.2+；Vue 3.0/3.1 可用普通 setup 和局部注册。

## SSR / Nuxt

组件在挂载后初始化。SSR 应用可使用组件或在 setup 中调用 useViewer；返回的 show() 方法应在浏览器事件处理函数中调用。

浏览器构建通过条件导出选择自动引入 CSS 的入口；Node.js / SSR 使用不导入 CSS 的同一份运行时实现。Nuxt 由客户端构建加载样式，服务端可以正常导入。
