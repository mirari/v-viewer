外观

v-viewer支持缩放、旋转等功能的 Vue 图片浏览组件

为 Vue 提供组件、指令与组合式 API，基于 Viewer.js。

快速上手
演练场
Vue 2

组件

通过属性、事件和方法控制图片浏览，使用插槽定制工具栏，自动监听内部图片变化。

指令

为现有元素添加图片浏览功能，自动监听内部图片变化，适合简单浏览和动态 Markdown、HTML 内容。

API

通过 useViewer 打开指定图片数组，适合按钮触发预览等场景。
