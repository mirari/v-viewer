v-viewerA Vue image viewer with zoom, rotation and more

Components, directives and composables for Vue. Powered by Viewer.js.

Get started
Playground
Vue 2

Component

Control the viewer with props, events and methods, customize toolbars with slots, and automatically track changes to images inside the component.

Directive

Add image browsing to existing elements and automatically track image changes, including dynamically rendered Markdown and HTML.

API

Open a specified image array with useViewer, for scenarios such as previews triggered by a button.
