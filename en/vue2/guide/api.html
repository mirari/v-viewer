API ​

Suitable for scenarios such as opening a specified image array after a button click.

Playground ​

Playground

vue
<script>
import Vue from 'vue'
import VueViewer from 'v-viewer'
Vue.use(VueViewer)
const sourceImages = [
  '/images/photo-01.jpg',
  '/images/photo-02.jpg',
  '/images/photo-03.jpg',
  '/images/photo-04.jpg',
  '/images/photo-05.jpg',
  '/images/photo-06.jpg',
  '/images/photo-07.jpg',
  '/images/photo-08.jpg',
  '/images/photo-09.jpg',
  '/images/photo-10.jpg',
].map((original) => ({
  src: original.replace('/images/', '/images/thumbnails/'),
  'data-source': original,
}))
export default {
  data() {
    return {
      sourceImages,
      images: sourceImages.slice(0, 5),
      options: { toolbar: true, url: 'data-source', initialViewIndex: 0 },
    }
  },
  beforeDestroy() {
    this.viewerInstance?.destroy()
  },
  methods: {
    add() {
      this.images.push(this.sourceImages[this.images.length])
    },
    remove() {
      this.images.pop()
    },
    show() {
      this.viewerInstance?.destroy()
      this.viewerInstance = this.$viewerApi({
        images: this.images,
        options: this.options,
      })
    },
  },
}
</script>

<template>
  <main class="viewer-example">
    <div class="controls">
      <button :disabled="images.length === sourceImages.length" @click="add">
        Add image
      </button>
      <button :disabled="images.length === 0" @click="remove">
        Remove image
      </button>
      <button class="open" :disabled="images.length === 0" @click="show()">
        Show viewer
      </button>
      <div class="toolbar" role="group" aria-label="Toggle toolbar">
        <span>Toggle toolbar</span>
        <button
          :aria-pressed="options.toolbar ? 'true' : 'false'"
          @click="options.toolbar = true"
        >
          On
        </button>
        <button
          :aria-pressed="options.toolbar ? 'false' : 'true'"
          @click="options.toolbar = false"
        >
          Off
        </button>
      </div>
    </div>
    <p>Images: {{ images.length }}</p>
  </main>
</template>

url: 'data-source' uses the image’s data-source attribute as the preview URL; initialViewIndex sets the starting image index (from 0).

Parameters and return values ​

this.$viewerApi({ images, options }) / viewerApi({ images, options }) returns a Viewer.js instance. Closing or destroying it removes the temporary gallery.

Call destroy() on page unmount to clean up an open gallery.

Access all Viewer.js methods on the instance. Viewer.js methods

Options ​

Pass these settings through options in viewerApi({ images, options }). The API always opens in modal mode. inline is fixed to false and cannot be overridden.

These match Viewer.js options. Each name links to its original documentation; available settings and defaults depend on the installed Viewer.js version.

Callbacks ​

Set callback functions such as viewed(event) in options. They correspond to Viewer.js events and receive the original DOM event, with operation data in event.detail. Click a name for its original documentation.

NameWhen it fires / useful data
readyThe viewer UI is initialized. In modal mode this can happen on the first opening.
show / shownBefore opening / after the opening transition completes in modal mode.
hide / hiddenBefore closing / after the closing transition completes in modal mode.
view / viewedBefore displaying an image / after it is displayed. detail.index is zero-based; image and originalImage identify the preview and source images.
move / movedBefore / after moving. detail.x, y, oldX and oldY describe the position change.
rotate / rotatedBefore / after rotation. detail.degree and oldDegree describe the angle change.
scale / scaledBefore / after scaling or flipping. detail.scaleX, scaleY, oldScaleX and oldScaleY describe the change.
zoom / zoomedBefore / after zooming. detail.ratio and oldRatio contain the zoom ratios.
play / stopBefore starting / stopping a slideshow.
playingBefore showing each slide during playback.
