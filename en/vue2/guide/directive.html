Directive ​

Suitable for simple image browsing without complex customization, while also supporting images in dynamically rendered Markdown or HTML whose content is not known in advance. By default, it watches additions, removals and attribute changes of <img> elements inside the element the directive is bound to and automatically updates the gallery.

Playground ​

Playground

vue
<script>
import Vue from 'vue'
import VueViewer from 'v-viewer'
Vue.use(VueViewer)
const sourceImages = [
  '/images/photo-01.jpg',
  '/images/photo-02.jpg',
  '/images/photo-03.jpg',
  '/images/photo-04.jpg',
  '/images/photo-05.jpg',
  '/images/photo-06.jpg',
  '/images/photo-07.jpg',
  '/images/photo-08.jpg',
  '/images/photo-09.jpg',
  '/images/photo-10.jpg',
].map((original) => ({
  src: original.replace('/images/', '/images/thumbnails/'),
  'data-source': original,
}))
export default {
  data() {
    return {
      sourceImages,
      images: sourceImages.slice(0, 5),
      options: { toolbar: true, url: 'data-source' },
    }
  },

  methods: {
    add() {
      this.images.push(this.sourceImages[this.images.length])
    },
    remove() {
      this.images.pop()
    },
    show() {
      this.$refs.gallery.$viewer.show()
    },
    onViewed(event) {
      console.log(event.detail.index)
    },
  },
}
</script>

<template>
  <main class="viewer-example">
    <div class="controls">
      <button :disabled="images.length === sourceImages.length" @click="add">
        Add image
      </button>
      <button :disabled="images.length === 0" @click="remove">
        Remove image
      </button>
      <button class="open" :disabled="images.length === 0" @click="show()">
        Show viewer
      </button>
      <div class="toolbar" role="group" aria-label="Toggle toolbar">
        <span>Toggle toolbar</span>
        <button
          :aria-pressed="options.toolbar ? 'true' : 'false'"
          @click="options.toolbar = true"
        >
          On
        </button>
        <button
          :aria-pressed="options.toolbar ? 'false' : 'true'"
          @click="options.toolbar = false"
        >
          Off
        </button>
      </div>
    </div>
    <div ref="gallery" v-viewer="options" @viewed="onViewed" class="gallery">
      <img
        v-for="(image, index) in images"
        :key="image.src"
        :src="image.src"
        :data-source="image['data-source']"
        :alt="`Landscape ${index + 1}`"
      />
    </div>
  </main>
</template>

Rendered HTML works the same way:

vue
<article v-viewer v-html="html" />

Binding and modifiers ​

BindingDescription
v-viewer="options"Accepts Viewer.js options. Deep changes rebuild the instance.
v-viewer="{ observe: false }"Disable automatic image DOM updates.
v-viewer="{ observe: 100 }"Batch image DOM changes in a 100ms window; default true uses 50ms, 0 adds no batching delay.
v-viewer="{ rebuild: true }"Recreate the instance when images change; defaults to false and supports reactive changes.
.rebuildShorthand for rebuild: true.

rebuild in the binding takes precedence over .rebuild, including an explicit false. When omitted or undefined, the modifier applies.

By default, additions, removals and attribute changes of <img> elements inside the element the directive is bound to automatically update the gallery. Access the instance as element.$viewer. Unmounting disconnects the observer and destroys the instance.

See automatic updates with observe for values, update timing and usage guidance.

ts
import type { ViewerElement } from 'v-viewer'
const element = document.querySelector<ViewerElement>('#gallery')
element?.$viewer?.show()

Options ​

Events ​

Viewer.js dispatches native DOM events on the HTML element bound to the directive. Listen using syntax such as @viewed. The handler receives the original event, with operation data in event.detail. Use @show.prevent to cancel opening.

vue
<div v-viewer="options" @viewed="onViewed">
  <img src="/images/photo-01.jpg" />
</div>
NameWhen it fires / useful data
readyThe viewer UI is initialized. In modal mode this can happen on the first opening.
show / shownBefore opening / after the opening transition completes in modal mode.
hide / hiddenBefore closing / after the closing transition completes in modal mode.
view / viewedBefore displaying an image / after it is displayed. detail.index is zero-based; image and originalImage identify the preview and source images.
move / movedBefore / after moving. detail.x, y, oldX and oldY describe the position change.
rotate / rotatedBefore / after rotation. detail.degree and oldDegree describe the angle change.
scale / scaledBefore / after scaling or flipping. detail.scaleX, scaleY, oldScaleX and oldScaleY describe the change.
zoom / zoomedBefore / after zooming. detail.ratio and oldRatio contain the zoom ratios.
play / stopBefore starting / stopping a slideshow.
playingBefore showing each slide during playback.

Callbacks ​

You can also set Viewer.js callbacks in options, using the names and parameters listed above:

js
const options = {
  viewed(event) {
    console.log(event.detail.index)
  },
}

When @viewed and options.viewed are both supplied, both run for the same event. Use either when they perform the same work.

Migrating from older versions ​

The .static modifier has been removed; replace it with { observe: false }.
